# 🎮 Games Reviews

A modern and responsive **Games Reviews** web application built to provide an engaging way to explore games and discover information about different titles.

The project focuses on creating a clean gaming interface with responsive design, interactive UI elements, and an enjoyable browsing experience.

---

## 🚀 Live Demo

🔗 **View Live Project:**
https://games-reviews-rose.vercel.app/

---

## ✨ Features

* 🎮 **Game Browsing** — Explore different games through an interactive interface.
* ⭐ **Game Reviews** — View game information and review-related content.
* 🔍 **Interactive Navigation** — Easily navigate through different sections.
* 🖼️ **Game Cards** — Display games in a clean and organized layout.
* 📱 **Responsive Design** — Works smoothly across mobile, tablet, and desktop devices.
* 🎨 **Modern UI** — Clean and visually appealing gaming interface.
* ⚡ **Fast Performance** — Optimized frontend experience.
* 🧩 **Reusable Components** — Organized and reusable UI components.

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Shahzaib-Shahid-27/Games-Reviews.git
```

### 2️⃣ Navigate to the project directory

```bash
cd Games-Reviews
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

---

## 📦 Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
